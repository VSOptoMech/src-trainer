# src-trainer

Minimal local-first Python web app scaffold for personal SRC (marine VHF radio) training, built with NiceGUI.

## Requirements

- Python 3.12+
- [uv](https://docs.astral.sh/uv/)

## Run locally

Install uv.

Run:

```bash
uv run src-trainer
```

Or:

```bash
uvx --from git+https://github.com/OWNER/REPO src-trainer
```
